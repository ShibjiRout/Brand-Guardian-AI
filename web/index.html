Features

What Brand Guardian does

It reads the full ad and looks up the rules that apply. It only reports what it can quote.

Reads the whole ad
It writes out everything that is said. It also reads any text shown on screen. Azure Video Indexer does this step.
Uses your rule documents
Upload your rules as PDF files once. Each ad is checked against the parts of those files that match what the ad says.
Quotes the ad
Every problem it reports includes the exact words from the ad. It ignores normal sales talk like "the best you'll ever feel".
Link or file
Paste a YouTube link. If the download does not work, upload the video file yourself.
How it works

How a video gets checked

There are five steps. Processing the video takes a few minutes, so the check runs in the background while the page waits for the result.

01
Get the video
The video is downloaded from YouTube, or you upload the file. It is then sent to Azure Video Indexer.
yt-dlp, Azure Video Indexer
02
Turn it into text
Azure writes out everything that is said. It also reads the text that appears on screen.
Speech to text, OCR (reading text from video frames)
03
Find the rules
The ad's text is compared with your rule documents. The three closest matching parts are picked.
OpenAI embeddings, Azure AI Search
04
Check the claims
GPT-4o compares the ad with those rules. It must quote the ad for every problem it reports.
GPT-4o
05
Show the result
You get a PASS or FAIL with a list of problems. Each problem has a type, a severity and a quote.
FastAPI

What it reports and what it ignores

The checking instructions were changed after real false alarms. It now leaves normal advertising language alone.

Built with
LangGraph GPT-4o Azure Video Indexer Azure AI Search FastAPI OpenAI Embeddings LangSmith Docker
Critical Claims with no proof, such as "guaranteed", "100% safe" or "clinically proven".
Critical Missing disclaimers that the FTC, the ASA or the platform requires.
Warning Claims that don't say if the result comes from the product itself or from how you use it.
Warning Claims close to the line that a lawyer should look at.
Ignored Normal sales talk and taglines that no viewer would take literally.
